# Суть проблемы

Дать возможность писать текст на линиях.

# Задача

> описание не закончено

Добавь отображение текста на линиях hline/vline. 
По умолчанию текст не отображается (`meta.hide_text` отсутствует). 
Выравнивание: top - для hline выше линии, для vline в верней части после стрелки; bottom - для hline

## Выравнивание текста на линиях

## hline

### Вертикальное выравнивание текста на hline

`top` - все строки текста находятся над линией, последняя строка примыкает к линии

`top`+`left`:
```text
  первая строка
  вторая строка
◇───────────────────────────────────────────▶
```

`bottom` - все строки текста находятся под линией, первая строка выводится сразу под линией

`bottom`+`left`:
```text
◇───────────────────────────────────────────▶
  первая строка
  вторая строка
```

`middle` - строки текста располагаются симметрично по вертикали от линии. 
Если число строк четное, то первая половина строк выводится сверху

`middle`+`left`:
```text
  первая строка
  вторая строка
◇─третья строка─────────────────────────────▶
  четвертая строка
```

### Горизонтальное выравнивание текста на hline

`left` - строки выравниваются влево, первые символы строки начинается в позиции +2 символа от левого края строки

`right` - строки выравниваются вправо, последние символы строки выводятся в позиции -2 символа от правого края строки

`middle`+`right`:
```text
                              первая строка
                              вторая строка
◇─────────────────────────────третья строка─▶
                           четвертая строка
```

`central` - строки выравниваются по горизонтали, выводятся от центра линии

`middle`+`central`:
```text
               первая строка
               вторая строка
◇──────────────третья строка────────────────▶
              четвертая строка
```

При любом выравнивании длина линии не меняется
