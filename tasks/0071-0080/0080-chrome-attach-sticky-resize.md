# Суть проблемы

Прилипание `header`/`footer`/`sidebar` в `box` (0074/0075/0077) —
render-time вывод по сохранённым относительным координатам. Сам
рендерер устойчив к ресайзу `box`, но редактор портит сохранённые
координаты: при росте `box` (любая грань, панель свойств) `footer` и
правый `sidebar` теряют условие прилипания
(`y + h > inner_h` / `x + w > inner_w` перестаёт выполняться) и
отклеиваются; group-ресайз `box`+chrome уезжает chrome внутрь и
удвоенно сдвигает детей; ресайз самого приклеенного блока раздувает
его сохранённые размеры. Спека —
`tasks/backlog/todo-0010-chrome-attach-sticky-resize.md` (согласована
2026-11-10).

# Задача

Гарантировать, что при любом ресайзе `box` (любой угол, панель
свойств, group-ресайз) приклеенные `header`/`footer`/`sidebar`
остаются приклеенными (вариант A: якорные формулы при коммите);
ресайз самого приклеенного блока пишет только перпендикулярное
измерение; `box` с приклеенными детьми клампится к 4×4; починить
удвоенный сдвиг детей в group-ресайзе. Рендерер и API не меняются.

# План работ

- [x] `static/js/editor.js`:
      - `_attachedSide(block)` — сторона прилипания (top/bottom/
        left/right) по тому же условию, что `_absoluteRect`
        (рефакторинг `_absoluteRect` на общий хелпер);
      - `_hasAttachedChildren(box)`;
      - `_anchorAttachedChildren(box, newSaved, N, M)` — якорные
        формулы спеки (`header: min(cy+N, −1)`,
        `footer: max(cy+N, inner_h'−ch+1)`, левый/правый `sidebar`
        зеркально);
      - одиночный `_commitBlockResize`: для `box` — кламп 4×4 +
        пакетный коммит с якорными children; для приклеенного
        блока — только `height` (`header`/`footer`) / `width`
        (`sidebar`), min 1;
      - group-ресайз: приклеенные дети исключены из трансформации
        (follow за `box`), `box`-участник с приклеенными детьми —
        кламп 4×4 + якоря; дельта позиции детей, чей родитель в
        группе, не применяется повторно (фикс удвоенного сдвига);
      - превью-дрег: приклеенный блок — только перпендикулярное
        измерение (min 1), `box` с приклеенными детьми — min 4×4;
      - панель свойств (`applyPropValue`, одиночная и мульти):
        `width`/`height` `box` с приклеенными детьми — кламп 4 и
        якорные children одним батчем.
- [x] Тесты e2e `tests/e2e/test_editor.py` (Playwright, дрег ручек):
      верхняя грань вниз N≥2 — header приклеен; рост снизу — footer
      приклеен; ресайз header только height; кламп 4×4.
- [x] Тесты рендера (фиксация деградации, правила не меняются):
      `tests/test_renderer.py` + `tests/js/test_renderer.js` —
      header+footer при жёстком сжатии, header с сохранённым `y ≥ 0`
      (не приклеен); parity-прогон.
- [x] AGENTS.md — строка про устойчивость прилипания к ресайзу `box`.
- [x] Прогон: `pytest tests/ --ignore=tests/e2e`,
      `node --test "tests/js/*.js"`, `pytest tests/e2e/` (сервер).

# Исследование

См. «Исследование» в спеке todo-0010. Уточнение по ходу реализации:
в текущем коде одиночный ресайз `box` детей НЕ пересчитывает
(исследование спеки п.2 описывало дрейф через `_absToRel`), но
отклейка `footer`/правого `sidebar` при росте происходит и без
дрейфа — из-за роста `inner_h`/`inner_w`, входящих в условие
прилипания. `header`/левый `sidebar` формально не отклеиваются
(условие не зависит от размера родителя), но якорная формула нужна
для корректной «щели» (согласовано: схлопывать до касания) и
единообразия.
