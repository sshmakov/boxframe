# Суть проблемы

Правило span-подавления из задачи 0062 (сегменты перегородок не
рисуются под прямоугольником ребёнка) не воспроизводит TO BE из
`change-cells-span.md`. Проверка (2026-10-31): в сценарии TO BE
(grid 38×11, 3×2, ребёнок-box 19×5 с рамкой double на (3,3), пересекает
ячейки 1–2 обоих рядов) вывод рендерера **побайтово совпадал с AS IS** —
«торчащие» концы на месте:

- перегородка между ячейками 1–2 (abs x=13) рисовалась над/под
  ребёнком (строки 1–2, 8–9) и frame-узлы `┬`/`┴` над ней не
  деградировали;
- горизонтальная перегородка (abs y=5) рисовалась в сегментах x=1–2 и
  x=22–24 (вне прямоугольника ребёнка), junction на (25,5) — `┼`, а не
  `├`.

TO BE нарисован по правилу **«целых ячеек»**: ребёнок, пересекающий
ячейки 1–2 обоих рядов, занимает весь 2×2-блок ячеек (левый 2/3 grid),
и перегородки внутри этого блока не рисуются целиком. Симуляция
(текущий механизм подавления + span-область = union целых ячеек)
воспроизвела TO BE побайтово.

Решение пользователя (2026-10-31): переключиться на правило «целых
ячеек».

# Задача

Span-область ребёнка = объединение **целых ячеек** grid, которые
пересекает его прямоугольник (bounding box пересекаемых ячеек), а не
сам прямоугольник. Перегородки внутри span-области не рисуются;
frame-узлы и junctions — по реально отрисованным сегментам (0063, без
изменений).

# Исследование

1. **Правило.** Для ребёнка с прямоугольником R (абс. half-open,
   кламп к внутренней области) пересекаемые колонки —
   `i: col_x[i] < R.x1 и col_x[i+1] > R.x0` (внутр. координаты), ряды
   аналогично по `row_y`. Span-область =
   `[col_x[i0], col_x[i1+1]) × [row_y[j0], row_y[j1+1])` (bounding box
   — пересекаемые ячейки всегда непрерывны по каждой оси, т.к. R —
   прямоугольник, а `col_x`/`row_y` строго возрастают).
2. **Суперпозиция 0062.** Span-область ⊇ прямоугольника ребёнка: всё,
   что подавлял 0062, подавляется и сейчас; плюс участки целых ячеек
   вне рамки ребёнка. Поведение без детей и с детьми, точно
   заполняющими ячейки, не меняется.
3. **Совместимость.** Вывод макетов с «невыровненными» детьми
   меняется: перегородки внутри задетых ячеек исчезают целиком (в т.ч.
   над/под ребёнком). Это суть TO BE.
4. **Parity.** Логика — целочисленные сравнения по тем же
   `col_x`/`row_y`, тривиально портируется; parity-тесты покрывают.
5. **E2E.** В сценарии e2e-теста (box 13×3 в ячейках 1–2 верхнего ряда
   grid 24×8) span-область = abs x [3,17) × y [3,6) — отличается от
   прямоугольника ребёнка ([3,16)×[3,6)) только в колонке x=16 (правая
   рамка ребёнка), где перегородок нет → вывод не меняется, тест
   пройден без правок.
