# Суть проблемы

На странице проекта макеты отображались списком карточек, но удалить макет из интерфейса
было невозможно: бэкенд-эндпоинт `DELETE /api/layouts/{id}` существовал, но в UI не
использовался нигде. Единственный способ удаления — прямой API-вызов. Проект при этом
удалялся через кнопку (HTMX) — асимметрия CRUD-возможностей в интерфейсе.

# Задача

Добавить возможность удаления макета из проекта:

- кнопка **Delete** на карточке layout'а на странице проекта;
- подтверждение перед удалением (имя макета в диалоге);
- карточка исчезает из DOM без перезагрузки страницы;
- покрытие тестами: каскад удаления блоков (API) и полный сценарий через UI (e2e).

# Исследование

1. **Бэкенд уже полный** — `DELETE /api/layouts/{layout_id}` в `api/layouts.py`,
   `LayoutService.delete_layout()`, каскад `cascade="all, delete-orphan"` на
   `Layout.blocks` (блоки удаляются вместе с макетом). Базовый API-тест
   `test_delete_layout` существовал, но не проверял каскад.
2. **UI-паттерн удаления уже есть** — в `projects.html` удаление проекта сделано через
   HTMX: `hx-delete` + `hx-confirm` + `hx-target="closest .card"` + `hx-swap="delete"` +
   классы `btn btn-danger btn-sm`. Кнопка — *сibling* ссылки `.card-link`, а не её потомок
   (иначе — вложенные интерактивные элементы, невалидный HTML).
3. **Playwright в venv (1.62.0) не имеет `page.expect_dialog()`** — метод отсутствует в
   установленной сборке. Рабочий вариант — обработчик `page.on("dialog", ...)` с
   `dialog.accept()`.
4. **Сьют `tests/e2e/test_drag_drop.py` бит (предсуществующее)** — тесты ждут текст
   «Preview» на странице редактора, которого нет после редизайна (задача 0010,
   коммит `1a1b98d`). К текущей задаче не относится.
5. **AGENTS.md** — в таблице API отсутствует строка `DELETE /api/layouts/{id}`
   (эндпоинт есть, документации нет).

# Замечания

1. **`test_drag_drop.py` требует отдельного фикса** — сьют не обновлён после редизайна
   редактора (0010): ждёт текст «Preview», которого в новом редакторе нет. Все 7 тестов
   падают на этапе создания layout'а.

2. **Playwright без `expect_dialog()`** — в установленной сборке (1.62.0) метода нет;
   для confirm-диалогов использовать `page.on("dialog", lambda d: d.accept())`.

3. **AGENTS.md устарел** — в таблицу API нужно добавить строку
   `DELETE /api/layouts/{id} | Удалить layout (каскадно с блоками)`.

4. **API-first подтверждён** — эндпоинт удаления существовал без UI; при добавлении
   новых CRUD-операций стоит сверять наличие UI-кнопки, а не только API.
