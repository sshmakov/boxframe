# Суть проблемы

Маркеры (горячие точки) на углах рамки выделения (`.sel-resize`)
центрируются на углах блока. Когда выделенный элемент небольшой —
например, 1 символ в ширину или 1 строка в высоту (vline, hline,
1×1 text) — четыре 18px-квадрата с иконкой-грипом сливаются в одно
пятно и полностью накрывают сам элемент: блок становится невидимым,
остаются только маркеры.

Это мешает базовому сценарию «выбрал маленький блок и вижу, что
выбран»: у vline/hline/1×1-текста содержимое (линия, символ)
закрывается маркерами, и непонятно, что именно выделено.

# Задача

1. На небольших размерах элемента держать маркеры на некотором
   расстоянии от него (отодвигать наружу от углов), чтобы сам элемент
   оставался видимым между маркерами.
2. Сделать маркеры круглыми и убрать иконки-грипы внутри.

# Исследование

1. **Маркеры — статические div'ы.** Четыре `.sel-resize--{nw,ne,sw,se}`
   лежат в `.block-selection` (Alpine `x-show`), позиционируются
   абсолютными координатами относительно рамки. Рамка сама
   позиционируется через `selectionStyle` (inline-стили) — значит,
   смещение маркеров можно выразить CSS-переменными, которые
   выставляются в этом же inline-стиле, без изменения DOM и без
   пересборки Alpine.
2. **Логика resize не зависит от позиции маркера.** Drag считается по
   дельте мыши от углов блока (`_startResizeDrag` + resize-ветка
   `onCanvasMouseMove`), а не от координат самой ручки. Поэтому
   отодвигание маркера наружу не ломает resize — курсор начинает
   drag чуть дальше от угла, но расчёт дельты от стартовой позиции
   мыши остаётся корректным.
3. **Порог «маленького».** Размер клетки на холсте ≈ 8×16 px
   (`charWidth`/`charHeight`, измеряются в `_measureCharSize`).
   Маркер 14px. Чтобы элемент оставался видимым, порог выбран в
   клетках: ширина < 3 клеток → смещение по горизонтали, высота
   < 2 строк → по вертикали. Смещение 12px даёт зазор ~5px между
   маркером и рамкой.
4. **Hover-ручка (`.resize-handle`).** Показывается при наведении на
   невыбранный блок (нижний правый угол). Для единообразия её тоже
   сделали круглой точкой без иконки — иначе два разных стиля
   маркеров в одном редакторе.
5. **Web и static синхронны.** Оба режима используют один
   `editor.js` и один `editor.css`; DOM-разметка рамки дублируется в
   `templates/pages/editor.html` и `static/editor/index.html`, но
   изменения касаются только CSS/JS — шаблоны не трогались.

# Выполнение задачи

Изменены 4 файла. Рендереры и формат псевдографики не тронуты.

**`boxframe/static/css/editor.css`:**

- `.sel-resize` — круглый маркер 14px (`border-radius: 50%`), без
  `::before`-иконки;
- `.sel-resize--{nw,ne,sw,se}` — позиции через
  `calc(-7px - var(--sel-ox, 0px))` / `calc(-7px - var(--sel-oy, 0px))`
  — по умолчанию центр маркера на углу рамки, переменные отодвигают
  наружу;
- `.resize-handle` (hover-ручка) — тоже круглая точка без SVG-иконки,
  hover-состояние — смена цвета.

**`boxframe/static/js/editor.js`:**

- `selectionStyle` — после вычисления bbox (`wPx`/`hPx`) считает
  `ox = wPx < 3*charWidth ? 12 : 0` и `oy = hPx < 2*charHeight ? 12 : 0`,
  выставляет `--sel-ox`/`--sel-oy` в inline-стиле рамки. Смещение
  по осям независимо: узкий высокий блок (vline) сдвигается только
  по горизонтали, низкий широкий (hline) — только по вертикали, 1×1 —
  по обеим.

**`tests/js/test_editor.js`** — 5 тестов на `selectionStyle`:

- крупный блок — маркеры на углах (`--sel-ox/oy: 0px`);
- 1-символьная ширина — смещение по горизонтали;
- 1-строчная высота — смещение по вертикали;
- 1×1 — смещение по обеим осям;
- multi-выделение — смещение считается по bbox группы.

**`tests/e2e/test_editor.py`:**

- `test_small_block_corner_handles_pushed_outward` — в браузере: у
  vline 1×10 SE-маркер полностью справа от рамки (по вертикали — по
  центру угла), у блока 20×4 — по центру угла.

# Замечания

1. **Порог и смещение — магические числа в `selectionStyle`.**
   3 клетки / 2 строки / 12px подобраны под текущий размер клетки
   (≈8×16px) и маркера (14px). Если изменят `font-size` холста или
   размер маркера — порог и зазор пересмотреть.
2. **Смещение по осям независимо.** Это осознанный выбор: у линии
   (1×N или N×1) маркеры сдвигаются только по тонкой оси, по толстой
   остаются на углах — так линия остаётся видимой, а лишнего «разлёта»
   маркеров нет.
3. **Resize не зависит от позиции маркера.** Drag считается от
   стартовой позиции мыши, поэтому отодвигание маркера наружу не
   влияет на точность resize. Если в будущем захотят «магнитить»
   курсор к маркеру — это отдельная задача.
4. **Hover-ручка тоже круглая.** Её стиль выровнен с угловыми
   маркерами. Если захотят различать «выделено» и «наведение» —
   сейчас это только цвет (акцентный vs серый).
