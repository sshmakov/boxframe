# Задачи boxframe

Папка задач проекта: каждая задача — отдельный markdown-файл с фиксированной
структурой. Задачи нумеруются по порядку и группируются в подпапки по десяткам.

## Структура

```
tasks/
├── 0000-template.md      # Шаблон новой задачи
├── 0001-0010/            # Задачи 0001–0010
├── 0011-0020/            # Задачи 0011–0020
├── 0021-0030/            # Задачи 0021–0030
└── backlog/              # Идеи без номера (todo-NNNN-*.md)
```

## Именование

- Задача: `NNNN-short-kebab-name.md`, где `NNNN` — четырёхзначный номер
  (например, `0027-editor-undo-redo.md`).
- Файл кладётся в подпапку соответствующего десятка: `0027-...` → `0021-0030/`.
  Если подпапки ещё нет — создать.
- Backlog: `todo-NNNN-short-kebab-name.md` — номер здесь только порядковый
  внутри backlog, не номер задачи.

## Формат задачи

Каждая задача строится по шаблону `0000-template.md` с разделами:

1. **Суть проблемы** — что обнаружено и к чему это ведёт
2. **Задача** — что нужно сделать
3. **План работ** — чек-лист (`- [ ]` / `- [x]`) запланированных шагов
4. **Исследование** — проведённые исследования и результаты
5. **Выполнение задачи** — что сделано и что не получилось
6. **Замечания** — что учесть в будущих работах

## Как создать новую задачу

1. Определить следующий свободный номер (максимум по существующим файлам + 1).
2. Скопировать `0000-template.md` в подпапку нужного десятка с именем
   `NNNN-short-kebab-name.md`.
3. Заполнить разделы.

## Как закрыть задачу

Отметить все пункты плана `[x]`, заполнить разделы «Выполнение задачи» и
«Замечания». Файл остаётся на месте — история задач не удаляется.

## Backlog

`backlog/` — идеи и наблюдения, ещё не ставшие задачами. Когда идея
конкретизируется, она получает номер и переезжает в подпапку десятка;
файл в backlog удаляется.
